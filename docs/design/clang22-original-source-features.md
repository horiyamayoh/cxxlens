# Original source feature observations

Monet's freestanding and portability consumers need original source populations
beyond function bodies. The versioned static domain visits every admitted original
Decl, Stmt, Attr and TypeLoc in the translation unit, including written globals,
field and default initializers, template syntax and unevaluated operands. It does
not instantiate missing templates or force compiler evaluation. The original
LangOptions freestanding flag is an independent compile-unit observation.

Each traversal occurrence has a unit-local ordinal. Repeated visits to the same
original native node additionally retain a separate original-node ordinal; neither
identity is a source deduplication or runtime occurrence. Raw compiler kinds and
names are retained observations. They do not classify language extensions or
hosted facilities. Those consumers still need independently captured policies or
supported compiler classifications; unsupported classifier members remain unknown.

The translation-unit inventory retains all admitted occurrences and every unbound
source occurrence. File populations use actual independently observed preprocessor
entry membership and the exact frozen file/snapshot pair. An unopened same-world
file is not synthesized as an empty population. Complete zero requires complete
entry, traversal and source attribution, not traversal completion alone. An
unresolved valid range prevents full eligible file closure.

An invalid compiler source range is retained. Source-none exclusion requires one
of three exact original grammar witnesses: an implicit Decl or Attr; an actual
CXXDefaultArgExpr or CXXDefaultInitExpr activation wrapper; or a TypeLoc in the
actual implicit declaration's owned TypeSourceInfo chain. An implicit enclosing
context does not exclude arbitrary children. Written child syntax remains an
independent observation even when an activation wrapper has no source range.

The LLVM-free `project_source_features` projection preserves environment,
enumeration, traversal, entry, source, context, entity, call, type and syntax axes
separately. Every original row is validated and charged, and conditioned duplicate
alternatives remain evidence. Optional missing targets do not erase native census
membership. Missing or contradictory source/file/unit references do prevent the
corresponding binding from becoming complete. Every empty file population still
validates its exact snapshot-to-file foreign key.

The native producer borrows existing collector identities and detaches bounded
owned rows. The public projection borrows inputs only during the call and retains
original annotations and query side channels. Work, storage, depth, member limits,
cancellation and unsupported traversal routes preserve explicit partial frontiers.
Measured overloads return charged work and conservative storage peak on success;
their usage output is zero on failure. Earlier saved inputs without these optional
facets remain unknown.

This slice does not close implicit resource activation, alias or object-version
domains, runtime read/write access, coroutine suspension, cleanup routes or the
compiler extension classifier. Their original factual censuses remain separate
dependencies.
