# ADR 0011: Provider の選択と実行

- Status: Accepted (revised 2026-10-03)

設定した実行ファイル、provider の ID/version、ABI/プロトコルと必要な機能で解析器を選ぶ。
異なる実行ファイルへの暗黙の切替や曖昧な候補は診断を返す。入力破損の検出、実行制限、
プロセス終了時の後片付けは通常の実行時検査として保持する。

品質証明書、認定レベル、署名付き認定台帳とその失効管理は削除する。作者自身が開発して
使うライブラリの利用開始を第三者の認定に依存させない。品質管理は Git と通常の試験で行う。

namespace は relation registry に記述した名前の所属を表す。解析結果の出典、coverage、
closure、未解決情報は実際の観測から返す。診断ツールによる機能の有無の確認は、個々の
解析結果の完全性の証明とは分けて扱う。
