# ADR 0127: Original target slots and CFG value bindings

Status: implementation draft in the isolated producer worktree.

Monet's `health.coverage.relation_resolution_ratio` needs all original eligible
consumer relation targets, including ownership, state access, inheritance,
overrides, nominal type positions and includes. Surviving call targets cannot
define that denominator. The virtual-call and local protocol consumers also
need actual dispatch and original CFG/value correspondence.

`cc.target_resolution_slot.v1` retains each compiler subject before normalized
target or source identity is required. Its identity uses compile unit, original
subject kind and structural traversal ordinal, domain, relation kind and slot
index; a resolved target is payload. Optional original declaration, syntax,
operation, include and edge references preserve exact joins where available.
No AST pointer is detached. The atomic `target_slot_count`, `target_slot_ids`,
`target_slot_state` and `target_slot_profile` fields on the original declaration
inventory enumerate this full per-unit domain independently of returned edges.

The profile `clang22-original-consumer-target-relations/1` includes actual
callable targets (written and compiler CFG actions), evaluated storage accesses,
written declaration membership, bases, overridden-method entries, recursively
observed declaration/base/template nominal type positions and evaluated include
directives. Actual builtin and non-nominal constructors retain excluded rows;
wrappers enumerate their children. Dependent or unsupported type eligibility
and dependent target resolution remain unknown. A completed native resolver's
explicit unresolved result is different from a missing target. Top-level
declarations retain their actual excluded named-owner classification.

Finite enumeration, eligibility, source/subject observation and target resolution
are independent axes. Equal duplicates preserve evidence; contradictory payloads
remain conflicting. A missing selected unit, recovery AST, unknown domain or
missing member cannot become a known empty denominator. Count admission happens
before source/normalization early returns. Existing producer bounds apply before
allocation and at every type/member traversal.

Dispatch facets on original calls/actions use the actual AST member invocation,
qualification and Clang devirtualization helper. Candidate sets state the exact
static materialized-AST interpretation; they never claim all runtime callees.
Direct, virtual, indirect, dependent and unavailable remain distinct.

Existing CFG edges retain the original condition syntax and true/false successor
position. Existing syntax retains actual conversion kind, child expression,
integer/null constant and compiler comparison opcode. Existing flow facts retain
their original expression, value expression, destination and definition IDs.
An element index is never converted to a flow program point. Receiver storage
identity does not establish pointee, alias, lifetime or normal-call completion.

Original syntax exposes distinct nonnull `Stmt::children()` members under
`clang22-original-statement-children/1`, alongside exact binary operands,
subscript base/index and conversion operand/type IDs. This is the original
statement child domain, not a proof of default-argument activation closure.
Compiler placeholder types such as BoundMember have no object layout; their
original builtin kind is retained with a partial structure frontier, without
calling Clang's object-size API.

The declaration identifier profile observes IdentifierInfo and its exact token
source, direct compiler scope and function attribution. Nonidentifier names
retain their actual kind and known absence. This facet is independent of finite
declaration membership. Function literal populations admit only IntegerLiteral,
FloatingLiteral and StringLiteral. Actual const/constexpr variable and enum
initializer ownership is retained by declaration ID. Written constructor
initializers are included; default/field activations lacking an exact original
view remain partial. No top-level file literal population is introduced.

The entity observer records the actual semantic named DeclContext by original
compiler identity. Transparent contexts introduce no owner; translation-unit
absence stays absent. The detached normalizer resolves parents before deriving
child entity identities because semantic_owner is an identity field. Missing,
contradictory or cyclic owner observations retain their original payload and
unresolved frontier with a provider-local identity and unobserved owner. An
unknown identity component cannot derive a canonical entity ID. Actual TU
absence is an explicit absent cell. It never appends an owner after deriving an entity ID,
or reconstructs it from names or source ranges. Older observations without this
optional facet retain their original identity and unknown consumer attribution.
The actual implicit lambda closure record is observed as the written call
operator's entity owner without admitting its synthesized members to the written
declaration population. Base-type and own-type target slots share one ordinal
sequence per original declaration; distinct nominal targets cannot collide at
the same slot index.

Declared automatic local-object populations retain each original declaration
type-use action, actual size, declared alignment and compiler ABI/target context.
Parameters, references, static/thread locals and compiler temporaries are outside
this explicit profile. Dependent/VLA layouts remain unknown members. The public
`project_function_compiler_facets` projection preserves independent occurrence
enumeration, static candidate presence and storage layout axes. A consumer must
supply an explicit accounting overhead policy; this input never claims an
optimized machine frame estimate.

The focused original-input compiler fixture exercises target domains, builtin
exclusion, qualified/final virtual calls, local layout, identifier/literal origin
and CFG branch/outcome joins. Pure SDK fixtures exercise missing/conflicting
admissions, world separation, bounds and cancellation. Full exceptional exit
enumeration still requires actual compiler EH carrier instrumentation: a throw
subset cannot complete that catalog metric. Missing source/type normalization
and unsupported default activation remain explicit frontiers. LLVM-free public
projections preserve original annotated rows, per-world coverage and evidence.
This is product semantic input; ordinary Git, logs and tests are the development
record.

## Original portability payloads on existing carriers

Raw pragma events retain a token-classified kind and its independent observation
state/profile. Known pragma grammar uses the actual first compiler identifier,
including GCC/clang diagnostic and visibility namespaces; unclassified vendor
forms remain unknown. No consumer parses event prose.

Each original ABI surface may additionally retain TargetInfo long/default-address-space
pointer/wchar widths, LangOptions plain-char signedness and TargetInfo byte order.
These observations belong to its actual compile unit/world and existing compiler ABI
context; no context digest is decoded. Actual complete record definitions separately
retain PackedAttr and MaxFieldAlignmentAttr values, including known absence.

StringLiteral rows retain compiler-decoded bytes, original encoding and element width
under a value profile, independently from original spelling and literal membership.
Invalid UTF-8 and embedded NUL remain byte payloads. Absent fields in earlier saved
queries stay unobserved. None of these optional facets weakens unrelated finite domains.
